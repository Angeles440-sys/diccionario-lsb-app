# Aplicación Diccionario LSB (Lengua de Señas Boliviana)

Aplicación interactiva y accesible diseñada en HTML, CSS y JavaScript para buscar y aprender palabras y señas básicas en Lengua de Señas Boliviana (LSB).

## Cómo ejecutar el proyecto
1. Abre el archivo `index.html` en cualquier navegador web.
2. Utiliza el buscador para filtrar palabras por categoría o nombre.
